# QueenQuery

Aplicação web para registro e recuperação de conhecimento técnico, desenvolvida no Projeto Integrador de Tecnologia da Informação II da UFMS.

## Objetivo
Facilitar a organização e consulta de anotações técnicas de estudantes, estagiários e profissionais em início de carreira em TI.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- Vue.js 3

## Funcionalidades implementadas
- Cadastro de registros técnicos
- Visualização dos registros cadastrados
- Edição e exclusão de registros
- Organização por categoria
- Registro automático da data
- Interface responsiva
- Pesquisa de registros por palavras-chave, considerando título, categoria, descrição técnica e solução ou procedimento.

## Como executar
1. Baixe os arquivos index.html e style.css na mesma pasta.
2. Abra index.html no navegador.
3. Mantenha a conexão com a internet para carregar o Vue.js.

## Limitações da versão inicial
Os registros ficam temporariamente na memória da página e são perdidos ao atualizar ou fechar a aplicação. A persistência em banco de dados está prevista para uma etapa posterior.
